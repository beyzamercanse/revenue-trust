Revenue Trust

Revenue models built from raw orders, refunds and a payment ledger, published only when every day reconciles, and a May→June bridge that traces the drop to a channel.

Simulated e-commerce scenario (seed 41), January–June 2025. Every figure is read from dashboard/data.json, which the pipeline writes. Run python3 dashboard/refresh.py after a new pipeline run.
